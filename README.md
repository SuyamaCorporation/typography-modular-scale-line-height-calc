# タイポグラフィ モジュラースケール &amp; 行高計算ツール

ベースフォントサイズ（px）と比率（Minor Second〜Golden Ratio）を選択するとモジュラースケール11段階を自動生成するツール。
各ステップのrm値・推奨line-height（文字サイズに反比例で1.1〜1.9）・推奨letter-spacingを算出する。
CSSカスタムプロパティ（--font-size-sm等）とtailwind.config.jsの両形式でコードを出力でき、ワンクリックでコピー可能。
Tailwindデフォルトtext-sizeとの対応表も付属。プレビューテキストを入力して実際のフォントサイズ表示も確認できる。

## 使い方

1. ベースサイズスライダーと比率セレクトで好みのスケールを設定する
2. スケール表で各ステップの数値を確認し、CSSまたはTailwind形式のコードをコピーする
